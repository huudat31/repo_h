# E-Commerce Platform Architecture
Tech Stack:
- Frontend: Next.js 15 (App Router, Tailwind CSS, TypeScript, SEO Optimized)
- Backend: NestJS (Clean Architecture, Modular, TypeScript)
- Database: PostgreSQL with Prisma ORM (support JSONB for dynamic product attributes)
- Cache & Search: Redis & Elasticsearch
- Integrations:
  - Payments: VNPAY & MoMo
  - Logistics / Shipping: GHN (Giao Hàng Nhanh) & GHTK (Giao Hàng Tiết Kiệm)
  - Notifications: Nodemailer & SendGrid
